# Запуск Electron и сборка Windows EXE

Для использования готового установщика эта инструкция не нужна. Достаточно скачать EXE из Releases.

## Подготовка

1. Установите Node.js 22+ и FFmpeg для Windows x64. FFmpeg должен поддерживать MP3 (libmp3lame), AAC, FLAC, Opus и PCM.
2. Выполните `npm ci`. Если менеджер пакетов пропустил установочный скрипт Electron, выполните `node node_modules/electron/install.js`.
3. Выполните `powershell -ExecutionPolicy Bypass -File setup.ps1` — скрипт загрузит yt-dlp из официального репозитория.
4. Положите в `tools/` файлы `node.exe` и `ffmpeg.exe`. Node.js обычно находится в `C:\Program Files\nodejs\node.exe`.
5. Положите лицензии и сведения об исходниках встроенных компонентов в `tools/licenses/`. См. [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

Использован FFmpeg Essentials от Gyan. Можно использовать совместимую Windows-сборку FFmpeg с необходимыми кодеками. Бинарные инструменты намеренно не хранятся в Git.

## Команды

```powershell
npm run desktop # окно приложения
npm test        # локальные проверки
npm run dist    # упаковка исходников и сборка NSIS-установщика
```

Результат: `release/YouMP3-Setup-<версия>-x64.exe`. Для передачи другому человеку достаточно одного EXE. Встроены Electron, Node.js, yt-dlp, FFmpeg, Essentia.js и локальное расширение поиска SoundCloud.

Исходники включаются в установщик как `resources/YouMP3-source.zip`; этот архив формируется заново перед сборкой. В нём нет треков, истории, настроек, `.git`, `node_modules` или бинарных инструментов. Не удаляйте лицензии при распространении сборки.

Сборка без сертификата издателя: Windows может показывать предупреждение. В версии 1.7+ обновления проверяются и скачиваются из GitHub Releases; установка запускается кнопкой в настройках после завершения активных задач. С 1.6 и более ранних версий один раз установите новый EXE поверх старого.

## Выпуск обновления

Повышайте `version` в `package.json` и `package-lock.json`, дополняйте CHANGELOG и отправляйте изменения в `main`. Workflow `.github/workflows/release.yml` запускает тесты, собирает Windows EXE и публикует новый релиз с установщиком, blockmap, `latest.yml` и архивом исходников. Достаточно стандартного `GITHUB_TOKEN` Actions с правом `contents: write`: отдельный секрет с личным токеном не требуется. Уже опубликованная версия повторно не перезаписывается.

## Данные и переменные окружения

Desktop использует случайный свободный порт на `127.0.0.1`, а данные хранит в `%APPDATA%\yoump3-local\audio`. История, файлы и игры сохраняются между запусками. Старые аудиофайлы подхватываются как архив; названия и ссылки, которые прежняя версия не сохранила, восстановить нельзя.

Для серверного запуска доступны `PORT`, `YTDLP_PATH`, `FFMPEG_PATH`, `YOUMP3_NODE`, `YOUMP3_DOWNLOADS`, `YOUMP3_EXPORTS` и `YOUMP3_SEARCH_PLUGINS`. В EXE пути встроенных инструментов задаются автоматически.

Для обновления yt-dlp замените `tools/yt-dlp.exe` официальной новой версией и пересоберите установщик. При обновлении FFmpeg обновите его лицензии и сведения об исходниках.
