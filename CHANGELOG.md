# 1.7.0

- BPM и тональность из описания YouTube/SoundCloud имеют приоритет над анализатором; отдельные источники для каждого значения, обработка конфликтов и сохранение ручных правок.
- Открытый в онлайн-плеере трек скрывается из списка результатов и возвращается при закрытии плеера.

- Незавершённые загрузки и очередь восстанавливаются после перезапуска. Частично скачанные файлы переиспользуются yt-dlp, когда источник это позволяет.
- Редактор названия, исполнителя, альбома и своей обложки; запись в новую версию файла с сохранением прежней внутренней копии.
- Ручное подтверждение BPM и тональности, ×2/÷2 и возврат к оценке алгоритма. Подтверждение не затирается повторным анализом.
- Подготовлены обновления через GitHub Releases: автоматическая проверка/скачивание и установка одной кнопкой. Установка блокируется, пока выполняются задачи. Для работы нужен опубликованный релиз с EXE, blockmap и latest.yml; до публикации проверка может сообщать об ошибке.
- GitHub Actions собирает установщик для новых версий и размещает файлы в Releases. Требуются права записи подключения/репозитория и разрешённый запуск Actions.

# 1.6.0

- Вкладка «Перерыв» с 16 играми: поймай ритм, угадай BPM, музыкальная память, угадай трек, выше/ниже, драм-секвенсор, змейка, 2048, арканоид, сапёр, пары, падающие блоки, реакция, лабиринт, судоку, кликер студии.
- Локальные рекорды и сохранения настольных игр, змейки, блоков, секвенсора и студии. Короткие музыкальные раунды, арканоид и реакция запускаются заново. Кнопка продолжения последней игры.
- Пауза, перезапуск, автоостановка при уходе в другой раздел или потере фокуса. Игры не мешают очереди загрузок; при завершении загрузки показывается уведомление во вкладке игр.
- Звук игр по умолчанию выключен. Включение останавливает основной плеер и онлайн-виджет. Угадывание трека требует минимум два готовых аудиофайла в библиотеке.
- Проверен запуск всех 16 игр в браузере и ход в 2048; 14 автоматических тестов прошли, включая 2048, сапёр, столкновения блоков, лабиринт и судоку.

# 1.5.0

- Обрезка на настоящей звуковой волне: два перетаскиваемых края, курсор прослушивания, масштаб 1×/2×/4×, повтор выделения и точные поля секунд. Оригинал остаётся без изменений.
- Звуковая волна строится локально FFmpeg и кэшируется рядом с аудио.
- Поиск SoundCloud больше не проверяет доступность обложки каждого трека. Локальное расширение yt-dlp возвращает ссылки из ответа поиска без дополнительных HEAD-запросов; браузер загружает картинки независимо после выдачи.
- Полное описание YouTube раскрывается в карточке результата и рядом с онлайн-плеером, загружается только по запросу.
- Проверено: реальные поиски обоих сервисов (~5–6 секунд на тестовых запросах), перетаскивание обоих краёв, прослушивание выделения, полное описание YouTube и 10 автоматических тестов, включая расчёт волны.

# 1.4.0

- Вкладка «Поиск»: YouTube и SoundCloud, запрос по исполнителю/названию, результаты с длительностью, автором и превью.
- Просмотр и прослушивание через официальные встроенные плееры. Для записей с ограниченным встраиванием доступно открытие оригинала в браузере.
- Добавление результата в очередь с выбором формата/качества; защита от дублей работает и в поиске.
- Догрузка результатов (до 30 YouTube / 18 SoundCloud), отмена поиска, кэш на 5 минут. Поиск не скачивает аудио и не требует отдельного ключа API.
- SoundCloud: выдача по 6 треков и короткое ожидание проверки превью. Изображения могут не отображаться при недоступности серверов обложек.
- Онлайн-плеер закрывается при переходе в другой раздел; локальное аудио и онлайн-плеер не играют одновременно.

# 1.3.0

- Нижний плеер: обложка, воспроизведение/пауза, перемотка, переходы между треками, ±10 секунд, громкость и избранное.
- Очередь ссылок: одна ссылка на строку, последовательное выполнение и отмена.
- Дубли распознаются по нормализованной ссылке, а короткие ссылки дополнительно проверяются по ID источника. Повтор можно разрешить явно.
- Обрезка: начало/конец в секундах, установка по позиции плеера, прослушивание фрагмента. Создаётся новая перекодированная копия; оригинал остаётся.
- Папка сохранения выбирается в настройках Windows-приложения. Новые загрузки и фрагменты автоматически сохраняются туда; по умолчанию — Downloads. Папка фиксируется при постановке задачи в очередь. Существующие файлы не перезаписываются.
- Имена файлов: исполнитель — название, когда источник предоставляет исполнителя. Для YouTube вместо исполнителя иногда доступно только имя канала.
- Метаданные title/artist/album и обложка в MP3/M4A/FLAC. Обложка YouTube может быть превью видео. Отключаются независимо для новых задач.
- Избранное, пользовательские теги, поиск по тегам. Сохраняются между запусками.
- Исправлен двойной контур фокуса полей; буфер обмена в EXE работает через ограниченный preload API.

Проверено: 8 автоматических тестов, аудиоплеер и редактор фрагмента в браузере. Анализ BPM и тональности сохранён. Кодирование фрагментов и запись обложек протестированы настоящим FFmpeg.
