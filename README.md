# YouMP3

**Локальное Windows-приложение для YouTube и SoundCloud: найти трек, послушать, скачать, обрезать и добавить в свою библиотеку.** Без подписки приложения и платных API.

[Скачать для Windows](https://github.com/L1nuxc/YouMP3/releases/latest) · [История версий](CHANGELOG.md) · [Сообщить об ошибке](https://github.com/L1nuxc/YouMP3/issues)

Предложения следующих функций: [ROADMAP.md](ROADMAP.md).

## Установка — для обычного пользователя

1. Откройте [Releases](https://github.com/L1nuxc/YouMP3/releases).
2. Скачайте файл `YouMP3-Setup-…-x64.exe` из раздела **Assets**.
3. Запустите установщик и откройте YouMP3 через ярлык.

Нужна **Windows 10/11 x64**. Node.js, yt-dlp и FFmpeg уже входят в готовый установщик: отдельно их устанавливать не нужно. Установщик пока не подписан цифровой подписью издателя.

Интернет нужен для поиска, онлайн-прослушивания и скачивания. Уже сохранённые файлы, обрезка, анализ и мини-игры работают локально.

## Что умеет приложение

| Раздел | Возможности |
| --- | --- |
| Поиск | YouTube и SoundCloud, превью, автор и длительность; встроенные онлайн-плееры; раскрываемое описание YouTube |
| Скачивание | MP3, WAV, FLAC, M4A и Opus; выбор качества; очередь, отмена и предупреждение о дублях |
| Библиотека | История и исходные ссылки, импорт своих файлов, поиск, фильтры, избранное и теги |
| Плеер | Перемотка, громкость, предыдущий/следующий трек и переходы на 10 секунд |

| Настройки | Папка сохранения, метаданные, обложки и обновление приложения одной кнопкой |
| Перерыв | 16 мини-игр с рекордами и сохранениями длительных партий |

### Как скачать трек

Найдите запись во вкладке **«Поиск»** и нажмите **«В очередь»**. Или вставьте одну/несколько ссылок во вкладке **«Скачать»** — по одной на строку. Выберите формат и качество. Готовый файл появится в библиотеке и сохранится в выбранную папку; кнопка **«Сохранить»** позволяет сделать ещё одну копию в другом месте.

Обложки и теги записываются, если источник их предоставляет. В MP3, M4A и FLAC поддерживается встроенная обложка; на YouTube это может быть превью видео. Иногда вместо исполнителя доступно только имя канала. Обложки и метаданные можно отключить для новых задач.

### Как обрезать и узнать тональность

В библиотеке нажмите **«Обрезать»**, перетащите края выделения на волне, прослушайте результат и создайте фрагмент. Он появится отдельным файлом; исходник останется.

При скачивании приложение ищет явные обозначения в описании: например, `BPM: 140`, `140 BPM`, `Key: F# minor` или `Тональность: фа-диез минор`. Найденные значения отображаются с пометкой **«Из описания»**; анализатор их не заменяет. Это сведения автора, их абсолютная точность не гарантируется. Несколько противоречащих значений не подставляются автоматически. Если указан только ключ без лада, приложение не придумывает major/minor.

Кнопка **«BPM / Тональность»** также получает описание для старых записей библиотеки. Для недостающих данных выполняется локальный анализ первых трёх минут. Оценка алгоритма может ошибаться, в том числе вдвое по BPM. **«Исправить BPM / ключ»** сохраняет ручные значения с наивысшим приоритетом; ×2/÷2 помогают поправить темп. Кнопка **«Теги файла»** меняет название, исполнителя, альбом и обложку.

### Все 16 мини-игр

Поймай ритм · Угадай BPM · Музыкальная память · Угадай трек · Выше или ниже? · Собери бит · Змейка · 2048 · Арканоид · Сапёр · Пары · Падающие блоки · Реакция · Лабиринт · Судоку · Своя студия.

Звук игр по умолчанию выключен. Для «Угадай трек» нужны минимум два готовых файла в библиотеке. Короткие раунды запускаются заново; настольные игры, змейка, блоки, секвенсор и студия сохраняют состояние.

## Ограничения

- Поддерживаются отдельные видео, Shorts, записи эфиров и отдельные треки SoundCloud. Плейлисты и прямые трансляции не поддерживаются.
- Приложение не обходит авторизацию, региональные ограничения или запрет встраивания. Для недоступного виджета есть открытие оригинала в браузере.
- Серверы обложек SoundCloud могут быть недоступны. Картинки загружаются отдельно и не блокируют выдачу треков.
- WAV/FLAC и больший битрейт не улучшают исходное качество записи.
- Сохраняйте контент, на скачивание которого у вас есть разрешение.
- В версии 1.7+ приложение проверяет GitHub Releases и скачивает обновления. В настройках нажмите «Установить и перезапустить». Для перехода с 1.6 и более ранних версий один раз установите новый EXE поверх старого. Во время активных задач установка откладывается.

## Где хранятся данные

В EXE-версии библиотека находится в `%APPDATA%\yoump3-local\audio`: аудио, история, теги, анализ и сохранения игр. Экспортированные копии находятся в выбранной папке, по умолчанию — «Загрузки». При запуске исходников используется локальная папка `downloads/`.

В репозиторий не входят пользовательские файлы, история, настройки, cookies, бинарные инструменты и зависимости npm.

## Запуск исходников

Для разработки нужны **Node.js 22+**, npm и FFmpeg. Это требования для исходников, а не для готового EXE.

```powershell
git clone https://github.com/L1nuxc/YouMP3.git
cd YouMP3
npm ci
powershell -ExecutionPolicy Bypass -File setup.ps1
npm start
```

Откройте `http://127.0.0.1:3210`. FFmpeg должен быть в `PATH`, либо задайте `$env:FFMPEG_PATH = 'C:\путь\ffmpeg.exe'`.

Для запуска окна Electron и сборки установщика прочитайте [инструкцию по сборке](DISTRIBUTION.md). Не запускайте исторические скрипты преобразования интерфейса: они не нужны для разработки.

## Проверки

```powershell
npm test
```

Тесты используют `tools/ffmpeg.exe`; положите туда FFmpeg для Windows. Проверяются аудиокодирование и обложки, библиотека после перезапуска, потоковое воспроизведение, очередь и обрезка, поиск, звуковая волна и логика нескольких мини-игр. Также проверяются разбор описаний, приоритет ручных значений и пропуск анализатора при наличии данных автора. Полная установка на чистой Windows пока не проверялась.

Опционально, при доступе к интернету: `node scripts/smoke.mjs` — реальные загрузки; `node scripts/check-search.mjs http://127.0.0.1:3210` — поиск на запущенном сервере.

## Технологии и лицензия

Electron, Node.js, yt-dlp, FFmpeg и Essentia.js. Интерфейс написан на обычных HTML/CSS/JavaScript. Сервер слушает только `127.0.0.1`; платный сервер для работы приложения не требуется.
