# YouMP3

**Музыка с YouTube и SoundCloud в вашей локальной библиотеке Windows.**
Поиск, прослушивание, скачивание, работа с аудио и четыре игры для перерыва.

[Скачать для Windows](https://github.com/L1nuxc/YouMP3/releases/latest) · [Сообщить об ошибке](https://github.com/L1nuxc/YouMP3/issues)

## Установка

1. Откройте [Releases](https://github.com/L1nuxc/YouMP3/releases).
2. Скачайте установщик YouMP3-Setup для Windows x64.
3. Установите приложение. При первом запуске появится короткая инструкция; её можно повторить кнопкой «Как пользоваться».

Требуется Windows 10/11 x64. В установщик входят Electron, Node.js, yt-dlp и FFmpeg.
Установщик пока не подписан сертификатом издателя.

Интернет нужен для поиска, онлайн-прослушивания, скачивания и проверки обновлений.
Сохранённые файлы, библиотека, обрезка, локальный анализ и игры работают офлайн.

## Возможности

- **Поиск YouTube и SoundCloud:** превью, исполнитель, длительность, оригинальная ссылка и описание.
- **Скачивание:** MP3, WAV, FLAC, M4A, Opus; очередь, отмена, повтор после ошибки и защита от дублей. Сервис определяется по ссылке; можно вставить ссылки разных сервисов, по одной на строку.
- **Библиотека:** обложки, список и таблица; поиск, сортировка, избранное, теги, подборки, фильтры по BPM, тональности и длительности.
- **Импорт и массовые действия:** несколько файлов через диалог или перетаскивание; выделение, добавление тегов и в подборку, экспорт, удаление с отменой.
- **Плеер:** очередь с перетаскиванием, перемотка, громкость, повтор и перемешивание; повтор участка A–B и запоминание позиции.
- **Правая панель:** видимые действия с треком, изменение ширины и сворачивание. Обрезка открывается в отдельном просторном редакторе.
- **Работа со звуком:** волна, масштаб, точные границы, прослушивание выделения и плавное начало/окончание фрагмента.
- **BPM и тональность:** значения из описания автора, локальная оценка недостающих данных и ручная коррекция.
- **Хранение:** проверка отсутствующих файлов, очистка временных версий, корзина, резервная копия аудио, библиотеки, настроек и прогресса игр.
- **Обновления:** приложение сообщает о новой версии. Скачивание начинается только после нажатия «Скачать обновление»; установка — отдельной кнопкой после завершения задач.

## Быстрый старт

**По ссылке:** откройте «Скачать», вставьте одну или несколько ссылок, выберите формат и качество, нажмите «В очередь». Можно смешивать YouTube и SoundCloud.

**Через поиск:** найдите трек, прослушайте и нажмите кнопку добавления в очередь. Громкость SoundCloud доступна рядом с онлайн-плеером и в нижнем плеере после подключения виджета.

**Свои файлы:** нажмите «Добавить аудио» или перетащите файлы в окно. Поддерживаются MP3, WAV, FLAC, M4A, Opus и OGG; до 200 МБ на файл.

**Обрезка:** выберите трек и нажмите «Обрезать трек» в правой панели. Установите начало и конец, прослушайте выделение и создайте отдельный фрагмент. Исходная запись останется.

**Подборки:** создайте подборку, выделите треки флажками и нажмите «В подборку». Плейлист хранит ссылки на записи библиотеки, без дублирования аудио.

## Горячие клавиши

| Клавиша       | Действие                               |
| ------------- | -------------------------------------- |
| Пробел        | Воспроизведение / пауза                |
| ← / →         | Перемотка; шаг выбирается в настройках |
| Shift + ← / → | Перемотка на 15 секунд                 |
| ↑ / ↓         | Громкость ±5%                          |
| M             | Выключить / вернуть звук               |
| Ctrl + F      | Поиск в текущем разделе                |
| Escape        | Закрыть меню или панель                |
| ?             | Подсказка по клавишам                  |

Клавиши плеера не перехватывают ввод текста и управление играми. Элементы доступны через Tab; вместо резких обводок используется подсветка фона.

## Четыре игры

| Игра            | Цель и управление                                                                                                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Своя студия** | Записывайте дубли, покупайте оборудование, выполняйте задания и развивайтесь до своего лейбла. Мышь, пробел или Enter. Офлайн-доход — 25% пассивного дохода, максимум за два часа. |
| **Змейка**      | Собирайте ноты и избегайте столкновений. Три скорости, стартовый отсчёт, стрелки/WASD и экранные кнопки. P — пауза.                                                                |
| **2048**        | Объединяйте одинаковые числа. Стрелки/WASD, кнопки или свайпы. Z — отмена последнего хода. После 2048 можно продолжать.                                                            |
| **Угадай трек** | Узнавайте фиксированные фрагменты из своей библиотеки. Нужны минимум два готовых файла. Пробел — прослушивание, 1–4 — ответ. Есть выбор длительности и отдельная громкость.        |

Правила доступны внутри каждой игры. Партии змейки, 2048 и развитие студии сохраняются автоматически. «Угадай трек» — короткая партия до пяти разных записей.

## BPM, тональность и метаданные

Явные значения вроде «140 BPM» и «Key: F# minor» берутся из описания с пометкой «Из описания».
Если значения отсутствуют, доступен локальный анализ первых трёх минут. Он может ошибаться, включая двойной или половинный темп.
Ручная коррекция имеет высший приоритет. Противоречивые сведения не подставляются автоматически.

Теги файла редактируются отдельно от тегов библиотеки. Запись метаданных создаёт новую версию аудио; временные версии можно очистить в настройках. Уже экспортированные копии не обновляются автоматически.

## Где находятся данные

В приложении Windows: %APPDATA%\yoump3-local\audio.
При запуске исходников: downloads/ в каталоге проекта, если не задан YOUMP3_DOWNLOADS.

Резервная копия создаётся в выбранной папке и включает аудио, обложки, метаданные, настройки интерфейса и сохранения игр.
Для восстановления выберите папку YouMP3-backup с файлом backup.json. Существующие записи не перезаписываются.
Создание и восстановление копии с аудиофайлами доступны в приложении Windows.

Удалённые треки сначала попадают в корзину. Её очистка удаляет только управляемые приложением копии.
Исходные импортированные файлы и отдельно экспортированные файлы не удаляются.

## Ограничения

- Поддерживаются отдельные видео, Shorts, записи эфиров и отдельные треки SoundCloud. Плейлисты источников и прямые трансляции не поддерживаются.
- Авторизация, региональные ограничения и запреты встраивания не обходятся. Для недоступного плеера можно открыть оригинал.
- Управление SoundCloud зависит от доступности официального виджета и его API.
- Обложки и метаданные зависят от источника. Вместо имени исполнителя иногда доступно только имя канала.
- WAV/FLAC или повышенный битрейт не улучшают качество исходной записи.
- Сохраняйте контент, на скачивание которого у вас есть разрешение.

## Запуск исходников

Нужны Node.js 22+, npm и FFmpeg.

```powershell
git clone https://github.com/L1nuxc/YouMP3.git
cd YouMP3
npm ci
powershell -ExecutionPolicy Bypass -File setup.ps1
npm start
```

Откройте http://127.0.0.1:3210. При необходимости задайте FFMPEG_PATH и YTDLP_PATH.
Для окна приложения: npm run desktop. Подготовка установщика описана в [DISTRIBUTION.md](DISTRIBUTION.md).

## Проверки и состав репозитория

```powershell
npm test
npm run test:ui
npm run format:check
```

Для аудиотестов нужен tools/ffmpeg.exe. UI-тест использует отдельную синтетическую библиотеку в build/ и не трогает личные записи.
Реальные сетевые загрузки: node scripts/smoke.mjs; поиск на запущенном сервере: node scripts/check-search.mjs.

В Git входят исходники, тесты, конфигурация, lock-файл, необходимые ресурсы интерфейса и лицензии.
Музыка, история прослушивания, сохранения, cookies, токены, зависимости, инструменты, сборки и тестовые скриншоты не публикуются в исходном дереве.
Архив исходников формируется по списку разрешённых файлов; установщики предназначены для Releases.
